## Outcome

Editors get diagnostics, completion and preview for `.tmpl` files from one protocol server, instead of a Visual Studio-only extension that this repository cannot verify.

## Problem

SPEC3306-US01-SC01 is blocked: a VSIX needs the Visual Studio SDK, a VS test host and would fail every CI leg. The same capabilities are reachable through a language server that any editor can host, and the engine already exposes `ValidateSyntax` with line/column diagnostics to power it.

## Contract decisions (lane-owned, resolved before implementation)

| Question | Decision |
|---|---|
| Protocol scope | LSP 3.17 over stdio: `textDocument/publishDiagnostics`, `completion` for `${Context.` paths and helper names, and a `workspace/executeCommand` preview that renders the current buffer |
| Transport | stdio only in this item; sockets and named pipes stay out so the server runs inside any editor host |
| Model source | the model type is declared in `.editorconfig`/plugin metadata, mirroring SPEC3323, so completion knows which members exist |
| Testing | the protocol loop is exercised through an in-memory stream pair, so CI can prove behavior without an editor |
| Relationship to the VSIX | the extension becomes a thin shell owned by a lane that packages Visual Studio tooling; this item delivers the server it hosts |

## Acceptance criteria

- [ ] UAC01: An `initialize`/`initialized` handshake over the in-memory stream pair completes and advertises the server capabilities.
- [ ] UAC02: `textDocument/didOpen` on a template with an `@else` and no `@if` publishes a diagnostic carrying code `TS007` and a one-based position.
- [ ] UAC03: Completion after `${Context.` returns the declared model's members and excludes unrelated ones.
- [ ] UAC04: Completion for a pipe helper name returns the registered helper names and no duplicates.
- [ ] UAC05: The preview command returns the rendered text for the current buffer revision, and a superseded request never overwrites a newer result.

## Scenario contract

Scenario `src/test/SPEC3324.LanguageServer/US01.Protocol/SC01_ServesEditorRequests.cs` drives the server through a loopback stream pair and asserts captured diagnostics, completion items and preview text.
