## Outcome

Tinytools provides a verified RazorLight-compatible memory cache contract and uses it correctly in the compatibility engine, with complete behavioral tests on every supported target framework.

## Acceptance criteria

- [ ] UAC01: A missing key returns an explicit miss; a cached key returns its own entry and template-page factory.
- [ ] UAC02: Keys use the documented comparer and remain isolated; adding or replacing one key never returns another key's cached page.
- [ ] UAC03: Page factories are lazy and invoked only when the engine retrieves/renders the cached entry; repeated operations follow the documented factory/replacement semantics.
- [ ] UAC04: `Contains` and `Remove` report the correct state before/after insertion, replacement and repeated removal.
- [ ] UAC05: Concurrent cache operations preserve per-key isolation and complete without corrupting entries; the tests assert only concurrency guarantees promised by the finalized contract.
- [ ] UAC06: The compatibility engine actually uses the configured cache for compile/render flows, reuses compiled template state, and renders a cached template with fresh model/context data without leaking prior render output.
- [ ] UAC07: The selected string, filesystem and embedded-resource project paths render expected results; missing templates and filesystem root-escape attempts produce the documented observable failure.
- [ ] UAC08: Invalid keys, null dependencies and invalid factories are either rejected with the documented exception or explicitly supported; every behavior is captured in an executable case.
- [ ] UAC09: Focused compatibility acceptance and the full test suite pass on `net8.0`, `net9.0` and `net10.0`, with no unexplained skips or omitted cases.

## Scenario contract

Use cases cover cache lookup/mutation and compatibility-engine rendering as distinct user goals. Each scenario has visible Given/When setup and calls, and named case results for miss, hit, replacement, removal, isolation, failure and rendering. Keep cache-provider contract tests separate from the existing internal compiled-template cache work (`SPEC3300-US07-SC01`); do not merge their APIs or acceptance evidence.
