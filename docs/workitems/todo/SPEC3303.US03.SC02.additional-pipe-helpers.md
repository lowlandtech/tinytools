### Bounded semantics

- `slice:start,end` uses zero-based UTF-16 string indexes, inclusive start and exclusive end. Equal in-range indexes yield the empty string. Negative, reversed or past-end bounds raise ArgumentOutOfRangeException; missing, non-integer or non-pair arguments raise ArgumentException. Null input remains null; no implicit collection slicing or negative-index language is added.
- `match:pattern` uses .NET regular-expression matching with default case-sensitive semantics, a fixed finite timeout of one second, and no compiled/global mutable pattern cache. Null input yields false. Missing/malformed patterns raise ArgumentException; a timeout remains RegexMatchTimeoutException and must not be reported as false. This scope does not add regex syntax to the pipe parser: patterns containing a pipe remain outside the existing delimiter grammar.
- `contains:value` uses ordinal case-sensitive substring matching for strings. For IEnumerable inputs other than string, it compares each element with the string argument using object.Equals, without converting numbers or changing case. Null input yields false; missing argument raises ArgumentException. String[] is the required positive collection fixture; numeric entries do not equal their textual spelling.
- `split:separator` treats a nonempty separator as a literal string and preserves leading, adjacent and trailing empty entries (StringSplitOptions.None). It returns string[]; null input returns an empty array. Missing/empty separator raises ArgumentException. No implicit regex separator, trimming or removal of empty entries is added.

These standard exception types are the named validation/refusal results; no second error hierarchy or global helper mutation is needed. Preserve existing unknown-helper behavior. SC03_AdditionalHelperBoundaries supplies twelve additional null, missing-argument, timeout, numeric-collection and slice-boundary Facts; preserve all twenty-four stable observations.
