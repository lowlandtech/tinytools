## Outcome

Callers can validate an engine template before render and receive a stable success or failure result for supported syntax.

## Acceptance criteria

- [ ] UAC01: A valid template returns a successful validation result and can still render its existing output.
- [ ] UAC02: Malformed control-flow or interpolation syntax returns a failed validation result with a useful diagnostic.
- [ ] UAC03: Validation does not execute template services or mutate the supplied execution context.
- [ ] UAC04: Render behavior remains unchanged for valid templates.
