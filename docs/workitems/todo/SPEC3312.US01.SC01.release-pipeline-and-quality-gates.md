## Acceptance criteria

- [ ] UAC01: Only one workflow can publish the NuGet package to a given feed; the unreachable `pack` job in `.github/workflows/main.yml` is removed or given a real trigger.
- [ ] UAC02: API-key secret names agree across the retained workflows and are documented where an operator can find them.
- [ ] UAC03: The known-vulnerable restores (`NCalc.Core`/`NCalcSync` and `Microsoft.Build.Tasks.Git`) are upgraded, or suppressed with a dated recorded reason.
- [ ] UAC04: Coverage either fails the build below a recorded threshold or the non-enforcing upload is removed.
- [ ] UAC05: The SDK matrix matches the project targets: the selected SDK builds and tests `net8.0`, `net9.0` and `net10.0` on every configured OS. The current `10.0.x` Windows and macOS legs must build the `net8.0`/`net9.0` test targets without missing `apphost.exe`/MSB3030 errors; no leg may silently skip its declared targets.
