## Outcome

Repeated rendering can reuse a compiled template while each render uses its own current context.

## Acceptance criteria

- [ ] UAC01: A compiled template renders the same source against two different contexts and returns each context's values without carrying rendered output between calls.
- [ ] UAC02: Repeated use of the same compiled representation avoids repeating the engine's compile/parse operation; a test collaborator counts compilation rather than relying on timing.
- [ ] UAC03: Different template source produces a distinct compiled representation, and concurrent renders preserve source and context isolation.

## Scenario contract

Use the native Tinytools engine only: one immutable template source, two context-specific renders and an observable compile count. This item does not add the RazorLight-compatible `ICachingProvider`, cache-key semantics, resource-project behavior or compatibility-engine wiring owned by M1-004 / #53. Keep each API and its acceptance tests separate.
