## Outcome

Reusable template packs can be distributed and discovered without enlarging the core engine runtime.

## Acceptance criteria

- [ ] UAC01: Given a valid package manifest, `PackIdentity` is stable and unique, and `EngineCompatibility` is a parseable range that admits the tested Tinytools engine version and rejects a version outside the range.
- [ ] UAC02: Given the selected distribution mechanism and an installed pack, `EnumeratedTemplates` lists only manifest-declared template data with stable names and package provenance.
- [ ] UAC03: Given a pack containing path traversal, executable content or undeclared files, `PackAdmissionResult` refuses the pack with a named reason before any content is rendered.
- [ ] UAC04: Given an admitted template containing text that resembles code or markup, `RenderedPackText` treats it as template data under existing Tinytools semantics and does not load or execute code from the package.
- [ ] UAC05: Given two packages declaring the same stable identity or template name, `CollisionResult` follows an explicit deterministic refusal/precedence policy and identifies both package identities.
