## Outcome

Templates cannot mutate process-wide helper state while other renders run, so helper behavior is the same for every caller in the process.

## Acceptance criteria

- [ ] UAC01: `TemplateHelpers.Helpers` is exposed read-only (`IReadOnlyDictionary` or an immutable dictionary); no public member returns a mutable helper collection.
- [ ] UAC02: Concurrent renders that use string, number, date and collection helpers produce the documented results without exceptions under a stress fact.
- [ ] UAC03: Callers that previously extended helpers through the mutable dictionary have a documented replacement path through `ExecutionContext.RegisterService`, and `changelog.md` carries the migration note.
- [ ] UAC04: Helper names, arguments and outputs are unchanged for every documented helper.

## Scenario contract

Add SPEC3310/US02. Given registers a service the way the migration note describes and prepares concurrent renders, When renders run in parallel, Then facts assert per-render output and the absence of shared-state mutation. Keep the stress case bounded so it stays deterministic.
