## Problem

The validator reports 19 RMP021 findings, all narrative documents under `docs/`. RMP021 forbids
repository docs guides and indexes: narrative belongs in workitems, reusable agent guidance belongs
in shared skills. Because the validator fails, `eng/workitems.py` refuses to run its issue preview,
so **every** issue reconciliation in this repository is manual and unverifiable. That is why #42 and
#86 needed hand-made state changes and why no mirror completeness can be claimed.
