## Outcome

Tools that read the repository's documentation decode every file and find no placeholder files, so the shared roadmap validator can run against this repository instead of aborting.

## Acceptance criteria

- [x] UAC01: Every tracked Markdown file under `docs/` decodes as UTF-8, with or without a byte-order mark.
- [x] UAC02: No tracked file is zero bytes; superseded instructions are removed or rewritten rather than left empty.
- [x] UAC03: `python eng/harness/validate_roadmap.py --repository-root .` runs to completion and returns its diagnostics instead of raising `UnicodeDecodeError`.
- [x] UAC04: Files that remain keep their text; the change is an encoding rewrite and deletion of empty placeholders, verifiable by reviewing the diff with whitespace ignored.
