## Outcome

The syntax diagnostics returned by `ITemplateEngine.ValidateSyntax` identify the source location and offending construct so callers can correct a template.

## Acceptance criteria

- [x] UAC01: A malformed construct on a later line reports its one-based line and column.
- [x] UAC02: An unexpected closing construct reports the location of that construct.
- [x] UAC03: Valid templates produce no diagnostics; malformed templates return diagnostics without rendering or partial-output claims.
- [x] UAC04: The syntax diagnostic extends the stable result contract from SPEC3302-US04-SC01 without changing the existing example-output validation result.
