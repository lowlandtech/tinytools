## Outcome

Templates can project one member out of a collection and aggregate numbers without a second helper or a workaround.

## Problem

`where`, `orderby`, `groupby` and `distinct` exist, but there is no way to pull a single member out of a collection (`select`), no numeric aggregate (`sum`, `avg`, `min`, `max`), and no `switch` control flow. Today a template author has to pre-shape the model in C#.

## Contract decisions (lane-owned, resolved before implementation)

| Question | Decision |
|---|---|
| Helper names | `select:path`, `sum`, `avg`, `min`, `max`; argument parsing and member reading follow the existing `where`/`orderby` rules so behavior stays consistent |
| Aggregate semantics | null and non-numeric entries are skipped rather than coerced; an empty sequence yields `0` for `sum` and null for `avg`/`min`/`max`, documented in the readme table |
| Numeric formatting | results interpolate with the invariant culture, matching SPEC3303-US05-SC01 |
| Control flow | `@switch (expr) { case value: ... }` is out of scope here and belongs to its own item so this one stays a helper change |

## Acceptance criteria

- [x] UAC01: `select:Name` on a collection returns the member values in source order and preserves duplicates.
- [x] UAC02: `sum`, `avg`, `min` and `max` return the documented values for a mixed numeric sequence and skip non-numeric entries.
- [x] UAC03: An empty or null sequence yields the documented zero/null results for each aggregate.
- [x] UAC04: A missing member path raises `ArgumentException` naming the path, matching `orderby`.
- [x] UAC05: Helpers chain left to right, so `where:Active==true | select:Name | join:, ` produces the expected text.
- [x] UAC06: The readme helper table documents every new helper with an example and its output.

## Evidence

Checkpoint after this change. `src/lib/Helpers/TemplateHelpers.cs` registers `select`, `sum`, `avg`,
`min` and `max` with the semantics the contract fixed.

- `select:path` reads the member through the same accessor the other collection helpers use, so a
  dictionary and an object behave alike, and a missing path is refused by name.
- The four aggregates convert with the invariant culture, skip null and non-numeric entries instead of
  coercing them, and return `0` for an empty `sum` and null for empty `avg`/`min`/`max`.
