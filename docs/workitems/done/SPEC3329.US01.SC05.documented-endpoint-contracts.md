## Outcome

The published contract describes what the host actually serves: stable operation identifiers, the security requirement, request and response shapes, and the error shapes - and CI fails when the host drifts from it.

## Problem

OpenAPI is mapped in development only and nothing compares it to the running host, so the document can be stale without anyone noticing.

## Acceptance criteria

- [x] UAC01: The served document publishes all seven template operations.
- [x] UAC02: Every published operation carries a stable identifier.
- [x] UAC03: The document declares the API-key security scheme.
- [x] UAC04: The document applies the security requirement to its operations.
- [x] UAC05: The served document matches the committed contract, so a change is a reviewable diff.
- [x] UAC06: The comparison refuses a document that drifted - an operation removed from a copy is reported.

## Divergence from the backend scope

The backend surface is `/api/plugins/{**path}` behind an account, device and IP model owned by the Auth
lane. Tinytools has one credential and seven template operations, and it deliberately refuses plugin
paths (`SPEC3315-US02-SC02`). Where the backend criterion depends on accounts or devices, this scope
requires the equivalent on this surface - credential scoping, provenance of the configured key, and
untrusted client headers - rather than inventing an account system here.

### What the contract was missing

The document published seven operations with correct identifiers and **no security scheme at all**:
a generated client would never have sent `X-Api-Key`. `OpenApiSecurity.DescribeApiKey` now declares
the scheme (apiKey in the `X-Api-Key` header) and applies it as a document-level requirement, so the
contract says what the route group already enforced.

### What the gate compares

`OpenApiContract.Differences` compares the facts a consumer depends on - the operation set with its
identifiers, and the declared schemes - and ignores formatting, ordering and descriptions. A
description edit is not drift; a renamed operation is.

### Scope of the gate

The comparison runs as an executed acceptance beside the host, not in CI: the API needs
`LowlandTech.Plugins.Domain` from the workspace feed, so `HostSpecs=false` excludes this folder.
That is the same prerequisite every host spec in this repository carries.
