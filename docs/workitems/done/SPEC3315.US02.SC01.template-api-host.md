## Evidence
- `src/core/Abstractions/ITemplateLibrary.cs` and `ITemplateExecutor.cs` hold the served contract; the library already owns the name `ITemplateService`, so the server contract is named `ITemplateLibrary` to keep both unambiguous.
- `src/api` hosts the seven operations on `/api/tinytools/templates`, renders through `LowlandTech.TinyTools` via `TemplateExecutor`, and persists through `TinyToolsDbContext` (schema `tinytools`) with the SQLite/Npgsql switch on `Host=`.
- Responses are DTOs, not entities: EF fixup populates `TemplateVersion.Template`, so serializing the entity recursed until the serializer failed with 500. `Contracts/TemplateContracts.cs` names the wire shape and drops back-references.
- Authorization is one policy; because the host runs no authentication scheme, a refused call is answered by `ApiKeyAuthorizationResultHandler` with 401 and a named error instead of a framework failure. Development allows anonymous, any other environment requires `X-Api-Key`, and an unconfigured key refuses rather than falling open.
- The database is created with `EnsureCreated`, not migrated: no migrations exist yet and the packaging item owns them. SQLite ignores the `tinytools` schema and logs EF warning 30000; the schema applies to Npgsql.
- Integration specs live on `net10.0` only, through a conditional project reference and `NET10_0_OR_GREATER`, because the host targets `net10.0` while the suite spans three frameworks.
