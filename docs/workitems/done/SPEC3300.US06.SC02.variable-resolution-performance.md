## Outcome

- [x] UAC04: The optimization passes named behavior cases for nested model-path resolution, chained pipe helpers and null-coalescing, including null and populated inputs.

## Fixed benchmark workload

Use a dependency-free console benchmark project at src/benchmarks/VariableResolution. Each process performs 2,000 warmup and 20,000 measured ITemplateEngine.ResolveVariables operations over the same fixed context and template:

Customer: ${Context.Model.Customer.Address.City | upper}; Owner: ${Context.Owner | trim | upper}; Alias: ${Context.Alias ?? "anonymous"}

Given model Customer.Address.City = "Amsterdam", Owner = " Ada ", and Alias absent or set to "ops", expected outputs are respectively "Customer: AMSTERDAM; Owner: ADA; Alias: anonymous" and "Customer: AMSTERDAM; Owner: ADA; Alias: ops". Each of five fresh Release process runs emits one machine-readable row with elapsed ticks, operation count, throughput and GC.GetAllocatedBytesForCurrentThread delta per operation. No wall-clock threshold is placed in the unit tests.

### What changed

- `GetPropertyValue` caches the reflected `PropertyInfo`/`FieldInfo` per `(Type, name)` in a `ConcurrentDictionary`, because the same handful of paths repeats on every render.
- Pipe segments are parsed with a span scan instead of `PipePattern().Matches(...)`, which removed a `MatchCollection` plus a `Match` per helper per expression. The argument rule was made explicit: whitespace before the next pipe is decoration and trimmed, whitespace at the end of the expression belongs to the argument, so `join:, ` keeps its comma-and-space separator while `split:; | count` still sees `;`.
- The three method-call patterns that were constructed per call are now static compiled fields, and the `Context.Get(...)` lookup reuses a static pattern.
- The per-match and per-helper debug logging is guarded by `_logger.IsEnabled(LogLevel.Debug)`, which removes the params-array allocation when debug logging is off.
- `ResolvePath` skips the `Split('.')` allocation when the expression has no dot.

One regression was caught by the suite during the work: the first hand-parsed version trimmed every argument, which broke `join:, ` (spacing lost in a rendered template) and the chained `split:; | count` case. The rule above fixed both, and the full suite is green.
